픽셀캠퍼스 | Windows 11 x64 실행 안내

1. ZIP 파일을 마우스 오른쪽 버튼으로 누르고 ‘모두 압축 풀기’를 선택합니다. 내 PC의 다운로드나 문서 폴더처럼 직접 쓸 수 있는 위치를 선택하세요.
2. 아래 사용 조건을 확인한 다음, 압축을 푼 폴더에서 PixelCampus.exe를 실행합니다. 다른 사람에게 전달하거나 다른 PC로 옮길 때는 ZIP 파일 전체를 보내 주세요. 앱과 같은 폴더에 들어 있는 DLL과 하위 폴더도 실행에 필요합니다.
3. 앱에 학교 로그인 화면이 뜨면 본인의 한림대학교 SmartLEAD 계정으로 로그인합니다. 로그인과 최신 자료 조회에는 인터넷 연결이 필요합니다.

동봉한 웹뷰를 열 수 없으면 앱이 Windows의 WebView2로 다시 시도합니다. 이 과정에서 창이 한 번 다시 열릴 수 있습니다. 그래도 로그인 창이 열리지 않으면 ‘오류 정보 복사’를 눌러 담당자에게 보내 주세요.

이 배포본에는 로그인 화면을 표시하는 Microsoft Edge WebView2와 필요한 Visual C++ 실행 파일이 포함되어 있습니다. Unity 에디터나 별도 런타임을 설치할 필요가 없습니다. WebView2 보안 업데이트는 새 배포본을 통해 제공되므로 최신 배포본을 사용해 주세요.
